# Ruby Introduction Course

Welcome to the **Ruby Introduction Course** repository by Bayt-al-Hikmah! This collection of lecture notes is designed for beginners and intermediate learners aiming to master Ruby programming fundamentals. Whether you're new to coding or refreshing your skills, these notes provide structured, step-by-step guidance through core concepts.

Bayt-al-Hikmah (House of Wisdom) is dedicated to preserving and disseminating knowledge, inspired by the historic intellectual center of the Islamic Golden Age. These lectures emphasize clear explanations, practical examples, and hands-on exercises to build a strong foundation in the Ruby language.

## Prerequisites

- Basic familiarity with computers and file management.
    
- No prior programming experience required (though helpful).
    
- Ruby installed (Ruby 3.2 or later recommended) or access to an online Ruby environment (e.g., Replit).
    

### Setup Instructions

1. Install Ruby:
    
    - **Windows/Linux/macOS**: Download from ruby-lang.org.
        
    - Alternatively, use an online tool like Replit with Ruby support.
        
2. Install an editor/IDE: Visual Studio Code with the Ruby extension is recommended for beginners.
    
3. Test your setup: Run a "Hello, World!" program (example in Lecture 1) using:
    
    ```bash
    ruby hello_world.rb
    ```
    

## Course Overview

This 5-lecture series covers essential Ruby topics progressively. Each lecture includes:

- Theoretical explanations.
    
- Code examples and snippets.
    
- Exercises for practice.
    
- References for further reading.
    


| Lecture   | Topic                                          | Key Concepts Covered                                                                           |
| --------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Lecture 1 | Variables and Input-Output                     | Variables, data types (Integer, String, Array, etc.), user input/output with gets/puts.        |
| Lecture 2 | Control Flow                                   | Logical/comparison operators, if-else statements, case-when statements, for/while/until loops. |
| Lecture 3 | Functional Programming, Modules, and Gems      | Blocks, procs, lambdas, module creation, using Ruby gems.                                      |
| Lecture 4 | Object-Oriented Programming and Error Handling | Classes, objects, inheritance, begin-rescue for error handling.                                |
| Lecture 5 | File Handling and Metaprogramming              | File I/O with File class, dynamic method definition, metaprogramming techniques.               |

**Recommended Pace**: 1-2 lectures per week, with time for coding practice. Total estimated time: 15-25 hours.

## Practice and Projects

- **Exercises**: Each lecture ends with coding challenges. Solutions can be added in a separate /exercises folder.
    
- **Mini-Project Ideas**:
    
    - Lecture 2: Simple command-line quiz app using control flow.
        
    - Lecture 3: Modular script for a task tracker using gems.
        
    - Lecture 5: File-based journaling app with metaprogramming features.
        
- **Resources**: ruby-lang.org for documentation, rubygems.org for gems, and Exercism Ruby track for problems.
